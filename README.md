# ai_code_workshop

AI-Assisted Large-Scale Scientific Software Development

Workshop material built with [Zensical](https://zensical.org/).

## Building the site

```bash
pip install -r requirements.txt
zensical serve   # live preview at http://localhost:8000
zensical build   # static site in site/
```

The site is deployed to GitHub Pages automatically on push to `main`
(see `.github/workflows/docs.yml`).
