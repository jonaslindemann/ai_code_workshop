# More examples

The [example repository](https://github.com/jonaslindemann/ai_coding_example)
contains more examples you can explore after the workshop. Each directory
has a `prompt.md` / `prompts.md` with the prompts used and a `final/`
directory with an example result.

## Python

| Example | Task | Prompts |
| ------- | ---- | ------- |
| [`python/countries/`](https://github.com/jonaslindemann/ai_coding_example/tree/main/python/countries) | Build a REST API client for restcountries.com and a tabbed Qt user interface, step by step over six prompts | [`prompt.md`](https://github.com/jonaslindemann/ai_coding_example/blob/main/python/countries/prompt.md) |
| [`python/qt_user_interface/`](https://github.com/jonaslindemann/ai_coding_example/tree/main/python/qt_user_interface) | Create a Qt user interface (via `qtpy`) for a beam model class | [`prompt.md`](https://github.com/jonaslindemann/ai_coding_example/blob/main/python/qt_user_interface/prompt.md) |
| [`python/general/`](https://github.com/jonaslindemann/ai_coding_example/tree/main/python/general) | A Qt `QMainWindow` application and a directory-traversal command-line tool | [`prompts.md`](https://github.com/jonaslindemann/ai_coding_example/blob/main/python/general/prompts.md) |
